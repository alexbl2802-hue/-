# Земли приключений — пакет исходников для GitHub Actions

Этот архив содержит исходники Godot и рабочий процесс `.github/workflows/godot-android.yml`, но **не содержит исходные GLB-модели и текстуры** из многотомного архива v2.0.65. Поэтому APK из одного этого ZIP гарантированно не собрать: теперь сборка останавливается с понятной ошибкой, а не выпускает пустую игру.

## Как собрать
1. Распакуйте архив **в корень репозитория** с сохранением структуры `.github/`, `godot/`, `tools/`.
2. Восстановите папки `godot/models/` и `godot/textures/` из полного многотомного архива игры v2.0.65 (либо предусмотренные `meshy/big/*.partNN`). Не заменяйте исходники файлами APK.
3. Загрузите изменения в ветку GitHub и откройте Actions → **Godot APK** → Run workflow; поле `bundle_tag` оставьте пустым.
4. После успешной сборки скачайте APK из Artifacts либо Releases. При первом запуске для загрузки PCK требуется доступность файлов `pack-*.pck` в том же релизе.

## Что включено
- Существующая система анимаций Hybrid Movement, ANIMATE и CARDINAL из версии 2.0.66.
- Проверка наличия ключевых файлов, моделей и текстур **до** дорогостоящей сборки.
- Сохранение основного игрового проекта и существующего GitHub Actions.

## Ограничения
- В этой среде Godot 4.7 и Android SDK не запускались; тесты на Android не выполнялись.
- Автоматическая сборка зависит от доступности релиза Godot 4.7, SDK и ключей подписи.
- Версия, присваиваемая workflow через `github.run_number`, может отличаться от версии исходников. Для обновления установленной игры нужен совместимый ключ подписи.
- В архиве нет готового APK. Не считать этот пакет подтверждённым релизом.
