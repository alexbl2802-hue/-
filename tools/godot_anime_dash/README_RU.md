# Аниме-рывок для Godot 4.7 (Android)

Скрипт реализует рывок-телепортацию: персонаж исчезает, затем появляется впереди. Поддерживает рывок с места и на бегу, направления вперёд, назад, влево и вправо относительно камеры. Это процедурная игровая механика, **не** файл анимации скелета Blender.

## Установка
1. Прикрепите `AnimeDash.gd` к узлу `CharacterBody3D` персонажа (если на нём уже есть контроллер, перенесите функции в существующий скрипт вместо замены).
2. В инспекторе назначьте `visual_root` — дочерний узел с видимой моделью, и `camera` — игровую камеру.
3. В Project > Project Settings > Input Map создайте действия `dash`, `move_left`, `move_right`, `move_forward`, `move_back`.
4. Для Android добавьте экранную кнопку `TouchScreenButton`, укажите Action = `dash`. Движение привяжите к вашему виртуальному джойстику.
5. Настройте `dash_distance`, `dash_duration` и `cooldown`.

## Ограничения
- Скрипт предполагает, что `CharacterBody3D` не имеет другого конфликтующего скрипта движения.
- Проверка препятствий — луч на высоте 1 м; для точной защиты от прохода сквозь стены лучше заменить её на shape cast с формой коллизии персонажа.
- Для 8 настоящих анимаций костей и экспорта в Blender нужен GLB персонажа со скелетом.
- Эффекты частиц и шлейф здесь не включены.
