# Земли приключений v2.0.65 — проект для Claude Code

Папка `godot/` содержит исходники Godot, `tools/` — скрипты сборки, `.github/workflows/godot-android.yml` — CI. В исходном архиве отсутствуют большие исходные модели и `godot/data/packs.json`: они создаются скриптами сборки и/или загружаются отдельно. НЕ объявлять APK готовым до успешного импорта, генерации manifest, экспорта и теста установки.

## Уже внесено
- CARDINAL: уже побеждённый босс не считается пройденным боевым тестом. Полноценный изолированный тест босса ещё предстоит реализовать.
- ANIMATE plugin.cfg и project.godot: версия 4.0 и версия приложения 2.0.65.
- Android preset: version/name=2.0.65.
- Boot: при отсутствии списка пакетов загрузка останавливается с понятной ошибкой вместо запуска игры без моделей.
- CI: импорт Godot и запуск редактора больше не игнорируют ошибки; после генерации пакетов выполняется проверка наличия, размера и SHA256.

## Обязательные действия Claude
1. Восстановить большие модели командой `sh tools/join_big.sh` (если доступны части); проверить наличие исходных моделей.
2. Запустить Godot 4.7 с экспортными шаблонами и Android SDK: `godot --headless --path godot --import`.
3. Сгенерировать `godot/data/packs.json` и `build/pack-*.pck` командой `python3 tools/data_pack.py /path/to/godot build`; проверить `python3 tools/validate_release.py godot/data/packs.json build`.
4. Экспортировать `godot --headless --path godot --export-debug Android ../build/ZemliPriklyucheniy-debug.apk`.
5. Проверить наличие manifest в APK и доступность PCK в опубликованном релизе с тегом, совпадающим с `application/config/version`.
6. На Android проверить запуск, загрузку PCK, управление, бой, сохранения, 15-минутный CARDINAL и FPS; устранить найденные ошибки и приложить логи.
7. Для босса сделать изолированное тестирование без изменения сохранения игрока. Для ANIMATE проверить реальные Skeleton3D и переходы. Для городской сцены измерить FPS/draw calls и оптимизировать по измерениям, не ухудшая исходные текстуры.
8. В workflow `godot-android.yml` есть устаревшие предположения о пути debug.keystore и Android SDK: проверьте их в CI; подпись и обновления поверх установленной версии должны быть проверены отдельно. Нельзя обещать обновление поверх установленного приложения с другим сертификатом без подтверждённой корректной ротации ключа.
