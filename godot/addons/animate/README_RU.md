# ANIMATE 0.1 (основа — CARDINAL Animation Generator 2.0)

В игре: окно ANIMATE открывается из окна CARDINAL (◈) — описание движения, длительность, амплитуда,
«Сгенерировать» (движение сразу показывается на герое), «Сохранить» (в память телефона,
user://animate/), список сохранённых. В редакторе Godot: плагин ANIMATE (панель справа).

Исправлено относительно присланной версии: поворот кости ставится поверх её позы покоя
(в Godot поворот позы — полный, а не добавка), имена костей Mixamo в Godot — mixamorig_*.


Godot 4.x editor addon for humanoid Skeleton3D animation prototyping.

## Установка
1. Распакуйте папку `addons` в корень проекта Godot.
2. Project → Project Settings → Plugins → включите `ANIMATE`.
3. Откройте сцену с GLB-моделью, содержащей Skeleton3D.
4. Выделите Skeleton3D или родительский узел модели в дереве сцены.
5. В панели ANIMATE нажмите «Использовать выделенный Skeleton3D / GLB».
6. Напишите описание движения (например, «быстрый бег») и нажмите «Сгенерировать».
7. Сохраните `.tres` в проект.

## Ручной редактор
Выберите кость, выставьте X/Y/Z, нажмите «Применить поворот», затем сохраните ключевую позу в начале, середине или конце. Повторите для других поз. Нажмите «Создать анимацию из поз» и «Сохранить».

## Подключение .tres к AnimationPlayer
1. Добавьте/выберите AnimationPlayer в сцене модели.
2. Установите `root_node` AnimationPlayer так, чтобы он указывал на Skeleton3D (относительный путь от AnimationPlayer).
3. В панели AnimationPlayer создайте или откройте AnimationLibrary и добавьте сохранённый ресурс `.tres` как анимацию.
4. Проверьте соответствие имён костей и анимационных дорожек. Дорожки вида `:BoneName` относятся к Skeleton3D, заданному в `root_node`.
5. Проиграйте анимацию и при необходимости отредактируйте ключи.

## Возможности и ограничения
- Текст обрабатывается правилами/ключевыми словами: walk, run, slash, dash, crouch, jump, wave, idle (и русские аналоги).
- Генерация процедурная; это не LLM и не система захвата движения.
- Для скелетов Mixamo и аналогичных предусмотрен поиск костей по именам; необычные риги потребуют расширения ALIASES.
- Анимации вращают кости, но не создают реального перемещения корневого узла; рывок не телепортирует персонажа.
- Для четвероногих существ нужны отдельные шаблоны.
- Ручной редактор сохраняет полные снимки поз и три предустановленных момента времени. Для произвольной временной шкалы нужен следующий этап.
- Плагин предназначен для запуска в редакторе Godot на ПК; экспортированные анимации можно использовать в Android-сборке.
- Код предоставляется как прототип и не проверен запуском в установленном Godot: тестируйте на копии проекта.
