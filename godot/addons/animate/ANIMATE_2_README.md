# ANIMATE 2.0 — экспериментальное обновление

## Установка
1. Сделайте резервную копию проекта Godot 4.7.
2. Скопируйте `addons/animate` и `scripts/ui` в корень проекта (или замените старые файлы).
3. В Godot: Project → Project Settings → Plugins → ANIMATE → Enable.
4. Откройте сцену с Skeleton3D, выделите модель и нажмите «Использовать выделенный Skeleton3D / GLB».
5. Генерируйте анимации, запускайте диагностику, сохраняйте `.tres`.

## Добавлено
- `inspector.gd`: диагностика скелета, пустых дорожек, некорректных времён ключей, ссылок на отсутствующие кости.
- `autofix.gd`: безопасное исправление **копии** ресурса Animation: удаление пустых дорожек и ссылок на отсутствующие кости, исправление нулевой длины.
- `skeleton_builder.gd`: ручное добавление вспомогательной кости к выбранному родителю.
- В `generator.gd` устранено повторное применение rest-поворота, защищён параметр fps, изменён приоритет распознавания рывка.
- В редактор добавлены кнопки диагностики, AutoFix и вспомогательной кости.

## Ограничения
- Код не запускался в редакторе Godot в этой среде; необходима проверка на Godot 4.7 и реальных GLB.
- Добавление кости **не создаёт веса вершин** и не исправляет геометрию. На импортированных GLB изменения могут быть перезаписаны повторным импортом. Используйте локальную копию сцены.
- Генератор использует эвристические шаблоны, не нейросетевую текстовую генерацию. Не создаёт полноценное root motion и IK.
- Автоисправление намеренно ограничено безопасными правками ресурса. Сложные дефекты анимации требуют ручного решения.
- Сохранён исходный игровой UI (`scripts/ui/animate_panel.gd`) без существенной переработки.
- Для воспроизведения `.tres` пути дорожек должны соответствовать настройке `AnimationPlayer.root_node`; настройка зависит от структуры сцены.
