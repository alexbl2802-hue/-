# Земли приключений — бесплатный боевой модуль (Godot 4.x)

Исходный код MIT. Никаких платных ассетов или зависимостей. Это **процедурные черновые анимации**, не готовый ретаргетинг под ваш GLB. Проверяйте на реальном скелете. Не содержит сторонних моделей.

## Установка
1. Распакуйте `addons/combat_pack` в корень проекта Godot.
2. В сцене героя добавьте Node с `combat_controller.gd`. Укажите AnimationPlayer и BoneAttachment3D левого предплечья.
3. Для щита: под Skeleton3D добавьте BoneAttachment3D, выберите кость левого предплечья (или кисти для центральной рукояти), под него добавьте Node3D со скриптом `shield_mount.gd`, затем меш щита. Поворачивайте `ShieldMount` так, чтобы щит лежал **снаружи** руки. Для динамической экипировки укажите в контроллере BoneAttachment3D; передавайте сцену щита с уже выставленным смещением корневого Node3D.
4. Для генерации анимаций добавьте Node с `procedural_animation_builder.gd`, задайте Skeleton3D, AnimationPlayer и **точные имена костей**. Выберите этот Node, откройте `demo/BUILD_ANIMATIONS.gd` в редакторе Godot и запустите File > Run (Ctrl+Shift+X). Сохраните сцену/библиотеку.
5. Свяжите кнопки Android: атака -> `attack_horizontal()` или `attack_whirlwind()`; нажатие защиты -> `start_block()`; после завершения start -> `hold_block()`; отпускание -> `stop_block()`. Для реакции на удар -> `receive_block_hit()`.
6. При смене предмета вызывайте `equip_shield(shield_packed_scene)` либо `unequip_shield()`.

## Важно
- Анимации вращают кости вокруг условных локальных осей и требуют ручной корректировки для конкретного рига. `whirlwind` пока **не выполняет реальное 360° вращение всего тела**, а задаёт вращение позвоночника: для полноценного вихря добавьте вращение RootMotion/визуального корня, синхронизируйте коллайдер и хитбокс.
- Движения не управляют уроном: подключите сигналы `attack_started` и боевые окна в CARDINAL. Сам сигнал не должен наносить урон без проверки пересечения хитбокса.
- После start/hit/end переходы следует доработать через AnimationTree или сигнал animation_finished; не вызывайте `hold_block()` каждый кадр.
- При экипировке разных щитов используйте отдельные сцены с корректным смещением; универсальное смещение для всех щитов не гарантируется.
- Для щитов с ремнями точка крепления — предплечье; для баклеров — кисть. Проверьте все ключевые позы, особенно блок и бег.
- Скелетные пути в AnimationPlayer должны разрешаться относительно AnimationPlayer.root_node; при необходимости настройте его в инспекторе.
- Тестируйте импорт и производительность на реальном Android-устройстве.
