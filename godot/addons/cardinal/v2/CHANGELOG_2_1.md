# CARDINAL 2.1
- Сохранены исходные модули CARDINAL 2.0.
- Добавлен Animation Guardian: аудит AnimationPlayer, проверка клипов, путей, ключей, циклов и переходов.
- Добавлены сигналы диагностики и экспорт отчёта JSON.
- Безопасное изменение default blend time доступно только по явному включению.
- Автоматический ремонт GLB, костей и ключевых кадров не заявлен: нужен исходный проект и модели.
