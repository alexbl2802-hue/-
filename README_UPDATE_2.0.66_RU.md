# Земли приключений — обновление плавности движения 2.0.66 (исходники)

Основа: последний подготовленный пакет v2.0.65. В обновлении доработан модуль `HybridCharacter`:

- буфер нажатий для последовательных ударов, чтобы не терялись команды;
- исправлена передача скорости падения при приземлении (до обнуления вертикальной скорости);
- необязательный клип сильного приземления `Land`;
- опциональный поворот визуальной модели во время рывка;
- дополнительные диагностические показатели комбо и буфера ввода.

Важно: модуль `HybridCharacter` — отдельная система, и существующий главный герой может использовать другой контроллер. Чтобы изменения проявились в игре, необходимо проверить сцену персонажа и интеграцию. В этом пакете не заявляется, что боевые анимации модели уже заменены. Система CARDINAL не изменена. Исходные текстуры не уменьшались.

## Установка

Архив `Zemli_v2.0.66_source_update.zip` содержит подготовленную исходную структуру v2.0.65 с изменённым модулем. Для точечной установки скопируйте `godot/hybrid_movement/scripts/hybrid_character.gd` из патча поверх одноимённого файла в проекте (после резервного копирования).

## Проверки перед APK

1. Открыть проект в Godot и проверить GDScript parser.
2. Проверить реальные сцены героя и вызовы `HybridCharacter`.
3. Проверить в игре комбо, рывок, прыжок, приземление, сенсорное управление.
4. Запустить 15-минутные тесты CARDINAL и экспортировать Android APK.

Здесь не запускались Godot и Android-эмулятор: работоспособность APK не подтверждена.
