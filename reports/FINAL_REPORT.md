## Что не завершено / заблокировано
- **Debug APK не собран (BLOCKED).** В окружении нет Android SDK (`ANDROID_HOME` пуст) и шаблонов экспорта Godot 4.7; хосты загрузки закрыты сетевыми правилами. `dist/` пуст — заглушки не создавались. Как собрать — ниже.
- **Не проверено на Android:** FPS, память, время загрузки, системный загрузчик DownloadManager, сенсорное управление на устройстве. Все цифры — с этого компьютера (без GPU) и без отрисовки.
- **Входные архивы задания** (`zemli_godot_project.zip`, APK 2.0.63, `packs game.*`) не были приложены — работа по исходникам репозитория; сравнение с APK не выполнялось.
- **I-30 (текстуры, OPEN):** ~957 МБ видеопамяти на текстуры моделей; ограничение до 2048 (~382 МБ) упрощает модели — нужно решение владельца.
- **I-16 (OPEN):** проверка «Босс и лестница» засчитывается, если страж уже побеждён в сохранении (без боя).
- **Не делалось (нет в игре, не придумывалось):** система заданий (реестр — SKIPPED), выносливость.
- Разбор описаний ANIMATE — **словарь, а не ИИ text-to-motion**; новые движения требуют новых шаблонов.

## Риски
- Профили «Среднее»/«Низкое» упрощают картинку вдали (LOD, деревья) — проверено глазами на этом компьютере, не на телефоне.
- Сгенерированные стойка и блок щитом заменили прежние клипы при соответствующем снаряжении (так требует ТЗ); на других скелетах не проверялось.
- Обход препятствий монстрами — локальный (лучи), не навигационная сетка: длинные лабиринты и тупики могут остаться непроходимыми.
- Новый вид `packs.json` появится только при следующей сборке в CI (`tools/data_pack.py`); локально сам сборщик не запускался.

## Как запустить
1. Godot **4.7** (`Godot_v4.7-stable`), из корня репозитория: `sh tools/join_big.sh` (склеить большие модели) → `godot --path godot` (игра) или `godot --headless --path godot --import` (импорт).
2. Проверки (все в `godot/tests/`, в APK не входят):
   `godot --headless --path godot res://tests/<тест>.tscn [-- <папка>]` — `load_all`, `save_safety`, `boot_packs`, `cardinal_limits`, `cardinal_timeout`, `cardinal_autoplay` (`-- <папка> 100000`), `animate4_demo` (`-- <папка>`), `animate4_window`, `hero_states_test`, `monsters_ai`, `items_dungeons`; с отрисовкой (xvfb или экран): `arts`, `skill_pages`, `ui_layout` (`--resolution WxH`), `perf_probe`, `animate4_demo` (кадры).
3. Режим администратора (окна CARDINAL и ANIMATE): 7 нажатий на номер версии в главном меню за 3 с.
4. Запекание клипов героя ANIMATE 4.0 (после правки шаблонов): `godot --headless --path godot res://tests/animate4_bake.tscn`.

## Как собрать debug APK
Нужно: Godot 4.7 + шаблоны экспорта 4.7 (`~/.local/share/godot/export_templates/4.7.stable/`), Android SDK (platform-tools, build-tools, platforms;android-34+), JDK 17+, debug-keystore (Godot создаёт сам или `keytool`).
```
sh tools/join_big.sh
godot --headless --path godot --import
python3 tools/data_pack.py <путь к godot> build          # пакеты данных + godot/data/packs.json
godot --headless --path godot --export-debug "Android" ../dist/ZemliPriklyucheniy-debug.apk
```
Либо GitHub Actions `godot-android.yml` (workflow_dispatch) на ветке `audit-4.0` — после того как владелец разрешит отправить ветку. Release APK с ключами — только с разрешёнными ключами (секреты репозитория), сюда не включались.
